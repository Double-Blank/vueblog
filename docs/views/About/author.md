## 个人介绍

你好，我是双击空格，一名拥有约 4 年前端开发经验、近 1 年独立产品开发经验的开发者。

我的技术背景主要集中在前端和全栈开发领域，熟练使用 React、TypeScript，具备 Vue 2 / Vue 3 项目开发经验。过去几年的工作主要围绕企业级业务系统、复杂交互界面、数据可视化以及前端工程化展开，接触过微前端架构、低代码平台、组件体系建设和跨端开发等方向。

在日常工作之外，我一直比较喜欢独立开发，也习惯通过 Side Project 探索新的技术方向。相比单纯完成业务需求，我更喜欢从一个想法出发，独立完成产品设计、技术选型、架构设计和功能落地。目前正在探索 AI 应用开发，也在尝试使用 React 构建自己的组件库。

**比较特别的一段经历是独立制作并发布了一款 Steam 游戏《王仙客想成为百万富翁》（WannaRich）。**

这是一个 2D 种田经营与冒险游戏，从最初的创意和玩法设计，到游戏客户端、核心业务逻辑、存档系统、战斗系统以及多人联机功能，基本由我一个人独立完成。

在技术实现上，我使用 Godot 进行客户端开发，基于 ENet 实现多人联机和专用服务器架构，并将服务端部署在阿里云 ECS 上。同时还需要处理客户端与服务端之间的通信协议、服务器权威逻辑、玩家状态同步、存档兼容性等问题。

这段经历让我从传统的前端业务开发拓展到了完整的软件工程实践，不仅需要编写代码，还需要考虑系统架构、数据一致性、异常处理、性能优化、测试和线上部署。项目开发过程中，我也深入实践了 AI Coding，使用 Cursor、Codex 配合 Spec-Driven Development（规范驱动开发）完成复杂功能开发，并通过 AGENTS.md 固化项目规范，累计编写 900+ 项无头回归测试，保障核心玩法、存档及多人联机功能的稳定性。

最终，我独立完成了游戏的开发，并推进到 Steam 平台发布流程。

目前，我希望继续深耕 AI 全栈开发方向，将自己在前端工程化、后端服务开发、AI Agent 和独立产品研发方面积累的经验结合起来，具备从需求分析、技术架构到产品交付的完整开发能力。
